# Sushant Pawar — Portfolio

This repository contains the source code for Sushant Pawar's personal portfolio website built with React and Vite.

Live demo
- https://portfolio-sushantpawar11.vercel.app/

What’s included
- Static single-page React app using Vite and Tailwind CSS
- Source files under `src/`
- Build output produced into `dist/`


Tech stack
- React 18
- Vite
- Tailwind CSS


Quick start (local)

1. Install Node.js (v18+) and npm.
2. Install dependencies:

```bash
npm ci
```

3. Run development server:

```bash
npm run dev
# Open http://localhost:5173
```

Build for production

```bash
npm run build
# `dist/` will contain the production build
```

Repository structure

- `index.html` — app entry
- `src/` — React source components
- `public/` — static assets
- `.github/workflows/deploy.yml` — CI/deploy workflow
